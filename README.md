# Enterprise Task & Operations Tracker (Kotlin)

## Description

A console-based task management utility built in idiomatic Kotlin for CSE 310 (Applied Programming). It demonstrates strong typing, null safety, collections, data classes, higher-order lambdas, and control flow expressions.

## Features

- Task registration with priorities (HIGH, MEDIUM, LOW)
- Mutable collection management and status tracking
- Dynamic prioritization filtering using `when` expressions
- Analytics summary generation
